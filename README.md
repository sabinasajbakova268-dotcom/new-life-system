# NEW LIFE SYSTEM v0.3

Личная локальная версия для установки как PWA через GitHub Pages.

## Установка/обновление
Загрузите содержимое архива в корень репозитория GitHub Pages, заменив файлы с теми же именами. Commit changes. Дождитесь публикации Pages. Если старая версия осталась в телефоне, закройте приложение, откройте сайт в Chrome и обновите страницу; при необходимости очистите кэш сайта.

## Функции
Профиль с редактированием имени/ID/аватара, локальное сохранение, задания и награды XP/CR, уровни и ранги, распределение очков характеристик, магазин, инвентарь, история CR, экспорт/импорт сохранения.

## Важно
Все данные хранятся локально в браузере (localStorage). Очистка данных сайта может удалить прогресс — регулярно экспортируйте резервную копию в Настройках. Реального сервера, синхронизации, чатов, проверки доказательств и автоматического расписания заданий пока нет.
