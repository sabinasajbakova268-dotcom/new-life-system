# NEW LIFE SYSTEM — v0.2

Обновлённый визуальный прототип: заставка, экран приветствия, главный RPG/HUD экран, шестиугольная панель характеристик и рабочая навигация между разделами.

## Запуск
Откройте `index.html` в браузере или разместите все файлы в корне GitHub Pages.

## Важно
Это фронтенд-прототип. Навигация и экраны работают, но аккаунты, синхронизация, реальные чаты, магазин с транзакциями, проверка заданий и серверное хранение пока не подключены.
