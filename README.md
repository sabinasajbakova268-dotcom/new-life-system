# NEW LIFE SYSTEM v0.5

Обновление личной PWA-версии NLS.

## Установка обновления
1. Распакуйте архив.
2. В GitHub откройте репозиторий `new-life-system`.
3. Загрузите файлы из архива в корень репозитория с заменой существующих файлов.
4. Сделайте Commit changes и дождитесь обновления GitHub Pages.
5. Откройте приложение и обновите страницу. Если старая версия осталась в кэше, закройте PWA и откройте сайт заново.

## Что нового
- Мастер создания персонажа: имя, лицо, причёска, цвет волос, глаза, возраст и рост.
- Выбор обычного происхождения; редкие происхождения предназначены для специальных заданий и достижений.
- Смешанное испытание класса: сюжет, характер, тактика и практический выбор.
- Система предлагает три класса по ответам; игрок выбирает один.
- Основной класс постоянный.
- Подготовлен слот для единственного дополнительного класса, который открывается отдельным сложным заданием.
- Отдельная страница игрового состояния персонажа.
- Сохранение продолжает использовать ключ `nls_personal_v03`.

Данные хранятся локально в браузере. Перед заменой файлов рекомендуется экспортировать резервную копию в настройках.
