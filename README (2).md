# NEW LIFE SYSTEM v0.4 — Character System

Личная локальная PWA-версия. Загрузите все файлы из архива в корень репозитория GitHub Pages, заменив одноимённые файлы, затем Commit changes.

## Новое в v0.4
- Экран персонажа с поворотом, визуальным обликом и слотами экипировки.
- Состояния персонажа: здоровье, голод, жажда, энергия, гигиена.
- Показатели постепенно меняются по времени, в том числе пока приложение закрыто. Персонаж не умирает: здоровье ограничено минимумом 1.
- Магазин с иллюстрированными карточками предметов: еда, напитки, уход, одежда, оружие, артефакты и предметы игрока.
- Экипировка предметов из инвентаря и расходование предметов.
- Подтверждение выполнения задания и необязательный текстовый отчёт.
- Для перехода с 1-го на 2-й уровень требуется 200 XP; порог увеличивается с каждым уровнем.

## Сохранения
Данные хранятся локально в браузере на этом устройстве. Обновление приложения не должно удалять сохранение, но очистка данных сайта может его удалить. Регулярно экспортируйте резервную копию в Настройках.

## Ограничения
Иллюстрации предметов — встроенные векторные мини-изображения, не загружаемые картинки. Персонаж пока стилизованная 2D-модель, поворачивается по шагам и имеет несколько визуальных слоёв экипировки; полноценная 3D-модель и анимации — будущая версия. Подтверждение задания локальное, не независимая проверка доказательств. Облачной синхронизации, чатов и серверных функций нет.
